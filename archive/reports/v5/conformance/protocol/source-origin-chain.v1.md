# Source-Origin Chain Qualification v1

## Purpose

Represent a new blind author working from an existing qualified v7 snapshot. Keep the existing `author_origin` adapter pinned to its original task, session, capture, and audit. This adds origin metadata only; it does not change semantic wire data, results, or conformance criteria.

## Qualification and exact record shape

The evaluator entry accepts this one new shape; all objects below reject extra fields and unsupported versions:

```json
{
  "kind": "author_origin_chain_v1",
  "chain": {"path": "reports/v5/conformance/review/<chain>.json", "sha256": "<raw sha256>"},
  "chain_review": {"path": "reports/v5/conformance/review/<review>.json", "sha256": "<raw sha256>"}
}
```

`chain` is strict JSON with exactly `format`, `record_version`, `evaluator_id`, `historical_baseline`, optional `predecessor_continuation`, `successor_input`, `successor_author`, `successor_audit`, `successor_output`, and `limitations`. `format` is `identitybench.v5.source-origin-chain.v1`; `record_version` is integer `1`; `evaluator_id` is the existing wire ID. The only omitted top-level field allowed is `predecessor_continuation`.

Shared nested forms (all hashes are lowercase 64-character SHA-256 values):

- `ArtifactRef`: exactly `{path, sha256}`; path is safe and repository-relative, digest is lowercase SHA-256 of raw bytes.
- `SourceMap`: exactly `{evaluator_id, source_profile, author_origin, files}`; `files` is the complete registered closure as ordered `{path, sha256}` rows with no duplicates. Profile/origin IDs are preserved as actually captured. They are not proof of human/task identity. A profile ID change is allowed only when the registry confirms identical evaluator and exact closure path set/order.
- `Capture`: exactly `{manifest: ArtifactRef, logical_sha256, source_map: SourceMap}`. Verify raw bytes, canonical manifest digest, source profile/origin, and every file row against the manifest. Safely hash every captured source file at `manifest.parent / file.path` and verify its declared size/hash; reading source text for semantics is unnecessary.
- `Prefix`: exactly `{session_id, start_offset_bytes, bytes, line_count, sha256, last_included_utc}`. `start_offset_bytes` is a nonnegative integer; counts are positive integers; timestamp is explicit UTC RFC3339. Capture cutoff is separately explicit as `{timestamp_utc, basis}`, where `basis` is `filesystem_mtime_weak`.

`historical_baseline` has exactly `adjudication`, `audit`, `executed_extractor`, `capture`, `author`, and `prefix`, plus optional `baseline_adjudication` and optional `reconstructed_inventory`. `adjudication`, `audit`, and `executed_extractor` are `ArtifactRef`; `capture` is `Capture`; `prefix` is `Prefix` with `start_offset_bytes: 0`; `author` is exactly `{task, session_id, source_profile, author_origin}`. Optional `baseline_adjudication` and `reconstructed_inventory` are `ArtifactRef` to separate strict JSON records. The frozen v7 record remains untouched and must satisfy its own old bindings to be valid under its legacy adapter.

If optional historical corroboration is unavailable, or a reconstructed inventory is used, `baseline_adjudication` is required and has exactly `record_type`, `record_version`, `adjudicator`, `decision`, `core_bindings`, `omitted_optional_corroboration`, `root_baseline_attestation`, and `limitations`. `record_type` is `source_origin_baseline_adjudication`, `record_version` is integer `1`, and `decision` must be `QUALIFIED_ELIGIBLE`. `adjudicator` is exactly `{task, route, reviewed_at_utc}`; it must differ from the historical author, and `route` uses the review route shape below. `core_bindings` is exactly `{audit, executed_extractor, capture, author, prefix, handoff}`; `audit`, `executed_extractor` are `ArtifactRef`, `capture` and `handoff` are `Capture`, `prefix` is `Prefix`, and `author` is the historical identity. Each omission is exactly `{path, old_sha256, reason}`; `reason` is a nonempty string and the array is sorted by path. `root_baseline_attestation` is exactly `{subject, source_map_sha256, basis_artifacts, issued_at_utc, statement, evidence_character, limitations}`; `subject` is exactly `{task, session_id, evaluator_id, source_profile, author_origin}` and equals the historical subject; `source_map_sha256` is `SHA256(canonical_json_bytes(handoff.source_map))`; `basis_artifacts` is a sorted unique array of `ArtifactRef` and includes the `reconstructed_inventory` ArtifactRef when present; remaining strings and `limitations` are nonempty. It binds every basis artifact without inventing historical time or fork claims. This new decision does not waive or repair the frozen record. Missing core capture, session prefix, executed auditor, or handoff blocks the chain.

`reconstructed_inventory`, when used, is a separate strict JSON artifact with exactly `format`, `record_version`, `reconstructed_at_utc`, `current_capture`, `files`, `completeness_decision`, and `limitations`. `format` is `identitybench.v5.source-origin-reconstructed-inventory.v1`, version is integer `1`; `current_capture` is an immutable `Capture`. It lists every registered closure path; each `files` row is exactly `{path, sha256, provenance}` with `provenance` an `ArtifactRef` for that component, and the ordered path/hash projection exactly matches `current_capture.source_map.files`. `completeness_decision` is exactly `{decision, reviewer_task, route, evidence, reviewed_at_utc}`; decision must be `PASS` to qualify, `route` uses the review route shape below, and `evidence` is an `ArtifactRef`. Its reviewer must differ from all source authors. The reconstruction is current: `reconstructed_at_utc` is the actual reconstruction time, never an inferred historical capture time. Its complete path-to-hash map must equal the historical capture's map when there is no predecessor continuation, or the predecessor output capture's map when there is one. Preserve all actual evaluator/profile/origin IDs; any profile ID difference must be justified by registered closure equivalence, not a rewritten identity. Historical evidence remains separately bound; this current capture does not replace it. The baseline attestation is outside this inventory artifact to avoid a self-hash cycle; it binds the inventory ArtifactRef and the canonical complete source-map digest.

`predecessor_continuation`, when present, has exactly `author`, `input_prefix`, `extension`, `output_prefix`, `audit`, `executed_extractor`, and `output_capture`. `author` is the exact historical author object. `input_prefix` and `output_prefix` are `Prefix`; `audit` and `executed_extractor` are `ArtifactRef`; `output_capture` is `Capture`. `extension` is exactly `{start_offset_bytes, bytes, line_count, sha256, last_included_utc}` and starts at `input_prefix.bytes`. Input prefix must equal the historical `(session_id, start_offset_bytes, bytes, line_count, sha256)` exactly; output prefix has that same session ID, starts at zero, and equals input plus extension in byte and line counts. The report and exact executed extractor bind the combined prefix. These are bounded audit metadata claims, not raw-log authenticity proof. Its `output_capture` is the immediate handoff. Without this node, the immediate handoff is `reconstructed_inventory.current_capture` when reconstruction is present, otherwise the historical capture. Never combine distinct sessions.

`successor_input` is exactly `{capture, source_map}`; its map must equal its capture's map and the immediate handoff's complete source profile and hash map. The immediate handoff is `predecessor_continuation.output_capture`, else `reconstructed_inventory.current_capture` if present, else `historical_baseline.capture`. A reconstructed capture map must equal the historical map when there is no predecessor, or the predecessor output map when there is one. `successor_author` is exactly `{task, session_id, source_profile, author_origin, spawn_evidence, root_attestation}`. The task and session must both differ from every historical author identity in the chain; this task/session/spawn binding establishes the new author, while profile/origin labels remain as actually captured and need not differ from historical labels. `spawn_evidence` is an `ArtifactRef` whose strict JSON record has exactly `format`, `record_version`, `task`, `session_id`, `parent_task`, `fork_mode`, `repository_root`, `input_source_map_sha256`, and `spawned_at_utc`; `format` is `identitybench.v5.author-spawn-evidence.v1`, version is integer `1`, and it binds those values. `fork_mode` is `fork_none`.

`root_attestation` is exactly `{subject, fork_mode, input_source_map_sha256, issued_at_utc, allowed_inputs, not_supplied, statement, evidence_character, limitations}`. `subject` is exactly `{task, session_id, evaluator_id, source_profile, author_origin}` and binds the successor; `fork_mode` is `fork_none`; `input_source_map_sha256` is the digest of the canonical complete input map. `allowed_inputs` is a sorted list of exact `{path, sha256, scope}` rows for the permitted inputs; `not_supplied` is a sorted unique list from the evaluator's fixed forbidden-input categories. `limitations` is a sorted unique list; `statement` and `evidence_character` are nonempty strings; timestamp is explicit UTC RFC3339. The attestation is supplied root evidence, not independently decryptable proof.

`successor_audit` is exactly `{report, executed_extractor, prefix, cutoff, disclosed_unknowns}`; `report` and `executed_extractor` are `ArtifactRef`, `prefix` is `Prefix`, and wrapper `prefix`, `cutoff`, and `disclosed_unknowns` exactly equal the report fields. The report bytes are strict JSON with exactly `{format, record_version, evaluator_id, author, prefix, output_capture, cutoff, executed_extractor_sha256, observed_path_events, forbidden_exposure, disclosed_unknowns}`. `format` is `identitybench.v5.successor-source-origin-audit.v1`, `record_version` is integer `1`; `evaluator_id` equals the chain evaluator; `author` is exactly `{task, session_id, source_profile, author_origin}` and must equal the corresponding identity projection of `successor_author`; `prefix` is exactly `{session_id, start_offset_bytes, bytes, line_count, sha256, last_included_utc}`, with the successor session ID and `start_offset_bytes: 0`; `output_capture` is `Capture` and must equal `successor_output`; `cutoff` is exactly `{timestamp_utc, basis}`, must equal the wrapper cutoff and bind the output capture manifest mtime, with `basis: filesystem_mtime_weak`; and `executed_extractor_sha256` must equal the raw SHA-256 of the wrapper's executed-extractor archive. `observed_path_events` is a sorted array of exact `{classification, path, evidence_sha256}` rows; classification is `ALLOWED` or `FORBIDDEN`, path is a nonempty string, and `evidence_sha256` is a SHA-256 of the emitted metadata event. `forbidden_exposure` is `NONE_OBSERVED` iff there is no `FORBIDDEN` event, otherwise `CONFIRMED`. `disclosed_unknowns` is a sorted unique array of exact `{code, evidence_sha256, reason}` rows; code and reason are nonempty strings and evidence hash is a SHA-256 or null when no byte evidence exists. The report must not emit source/message content. A confirmed forbidden event fails qualification; declared bounded unknowns remain coverage limits, not isolation proof. `successor_output` is exactly one `Capture`; successor input and output must use registered equivalent closures, with full maps allowed to differ only through the recorded author edits.

`chain_review` is strict JSON with exactly `format`, `record_version`, `chain`, `referenced_artifacts`, `checks`, `decision`, `reviewers`, and `limitations`. `format` is `identitybench.v5.source-origin-chain-review.v1`, version is integer `1`. `chain` is an `ArtifactRef` to the exact chain bytes; `referenced_artifacts` is the sorted, duplicate-free set of every nested `ArtifactRef` path/hash. `checks` is exactly `{baseline_core, transitions, author_separation, artifact_hashes, forbidden_exposure, omissions, coverage_limits}`. Values are `PASS`, `FAIL`, or `UNKNOWN`, except `coverage_limits`, which is `ACKNOWLEDGED_UNKNOWN` or `UNREVIEWED`. `decision` is `QUALIFIED_ELIGIBLE`, `INELIGIBLE`, or `UNKNOWN`; reviewers have exactly `{task, decision, route, reviewed_at_utc}`, with decision `PASS`, `FAIL`, or `UNKNOWN` and route `{model, reasoning_effort, provider, service_tier}` (all route values are nonempty strings). Require at least one reviewer, reviewer tasks distinct from each other and every author in the chain, and all reviewer decisions `PASS` for eligibility. `QUALIFIED_ELIGIBLE` requires every ordinary check `PASS` and `coverage_limits: ACKNOWLEDGED_UNKNOWN`; a forbidden-exposure check of `FAIL` or reviewer `FAIL` yields `INELIGIBLE`; reviewer `UNKNOWN`, any other failed check, or an unreviewed check yields `UNKNOWN` and blocks qualification.

Chain v1 supports exactly the historical author, at most one same-session predecessor continuation, and one successor author. The optional predecessor is the same historical author, not a new author. If any actual author or source transition is unrepresented, reject v1. A later author requires another explicit versioned transition. `limitations` fields are sorted arrays of nonempty unique strings. All required timestamps are UTC RFC3339 metadata, not cryptographic chronology.

## Decisions and compatibility

- Add a separate `author_origin_chain_v1` dispatch in `validation.py`. Preserve current `author_origin` and production branches, exact legacy pairs, original-author pins, and v7 decoders. Do not rewrite old records or legacy meanings.
- Verify every raw artifact hash, manifest logical hash, complete ordered closure, and exact handoff map. Compare actual profile IDs as recorded; profile/origin equality is not author identity. If a new registered `SourceProfile` pair is needed because the current type couples profile to origin, it is a compatibility choice with the same exact closure, not a chain rule.
- `QUALIFIED_ELIGIBLE` remains conditional on the root attestation and a passing complete chain review. Report `source_isolation: UNKNOWN` and weak filesystem chronology; do not claim OS-level completeness, log authenticity, cryptographic ordering, or global absence. Known bounded audit coverage unknowns stay explicitly `UNKNOWN` and reviewed under the existing conditional semantics; they do not silently become proof or automatically invalidate an otherwise complete legacy baseline. They do not change qualification status solely by being disclosed. Unsupported required schemas, unbound core/handoff evidence, and stale/missing hashes always block with `UNKNOWN`. Actual forbidden exposure overrides attestation and yields `INELIGIBLE`.
- A reconstructed inventory reports only the present reconstruction time. No earlier capture time or authorship may be inferred from preserved hashes. Independent review must make an explicit completeness decision and bind a root baseline attestation.
